# Návrhy a plány (proposals)

Složka shrnuje nápady z konverzace o transformaci swingerslife.cz na Libertin.
**Nejde o smluvní rozsah.** Rozsah určuje `docs/backlog.yaml` (viz CLAUDE.md). Nic z toho se do backlogu nepřenáší bez rozhodnutí vlastníka.

## Obsah

- `01-strategie-a-monetizace.md` – trh, konkurence, cena, 90denní plán
- `02-kontaktni-dosah.md` – doručování příspěvků přes telefonní kontakty, utajený autor, odhalení
- `03-uvodni-obrazovka/` – koncept úvodní obrazovky (kód je `.draft`, mimo build) a texty
